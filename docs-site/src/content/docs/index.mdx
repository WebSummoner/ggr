<CardGrid stagger>
  <Card title="Stateless by design" icon="random">
    Run as many instances as you like behind a load balancer. The hub host is
    encoded into the session ID, so any instance can serve any request.
  </Card>
  <Card title="Quota per user" icon="document">
    Each user gets an XML quota file describing the browsers, versions, regions
    and hosts available to them.
  </Card>
  <Card title="Proxies everything" icon="puzzle">
    Video, logs, downloaded files, VNC traffic and developer tools are all
    proxied through Ggr using the session ID your test already has.
  </Card>
  <Card title="Works with external services" icon="external">
    Point a quota entry at Saucelabs, BrowserStack or TestingBot and Ggr routes
    to them with the credentials from the quota file.
  </Card>
